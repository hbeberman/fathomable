# Security

## Scope

Fathomable is pre-release. Please report vulnerabilities affecting the current
`main` branch or the latest published alpha. Security fixes will not be
backported to older releases.

## Responsible disclosure

Use GitHub's
[private vulnerability reporting form](https://github.com/hbeberman/fathomable/security/advisories/new).
Do not disclose an unaddressed vulnerability in a public issue, pull request,
discussion, commit, or log.

Include the affected version or commit, prerequisites, impact, and the smallest
useful reproduction.
Reports are handled on a best-effort basis without a guaranteed response or
remediation timeline.
