# fathomable-core

Terminal-free core library for [Fathomable](https://github.com/hbeberman/fathomable).
Provides document loading, Markdown layout, syntax highlighting, Git diffs,
review threads, review points, sessions, and configuration.

For the terminal viewer and MCP server, install
[`fathomable`](https://crates.io/crates/fathomable) instead.

[API documentation](https://docs.rs/fathomable-core).

Requires Linux and Rust 1.95+. Early alpha: APIs and saved state may change between releases.
